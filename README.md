# 🐱 문캣 - 달에서 집으로

달에 불시착한 고양이 '나비'가 부품을 모아 로켓을 고치고 지구로 돌아가는 턴제 미니 게임.

- 파이썬 표준 라이브러리만 사용 (tkinter, json, wave, winsound) → 설치할 것 없음, 유료 API·서버 없음
- 모든 행동 직후 자동 저장 → 언제 꺼도 다음 실행 때 그대로 이어짐 (선택지 창이 떠 있던 것까지)

## 실행

```
python main.py                                  # 게임
python -m unittest discover -s tests -t . -v    # 테스트 (15개)
build.bat                                       # 실행 파일 만들기 → dist\MoonCat.exe
```

## 게임 방법

```
기지(산소 충전·휴식·수리) ──이동──▶ 지역 탐색(산소·체력 소모, 부품 획득, 새 지역 발견)
        ▲                                         │
        └──────── 귀환 (산소 0이면 기절해서 강제 귀환 + 아이템 1개 분실) ◀┘
수리 9/9 → 발사 → 엔딩          기절이 난이도별 한도에 닿으면 → 게임오버
```

| 자원 | 역할 |
|---|---|
| 산소 | 이동·탐색 시 감소. 기지에 오면 가득 참. 0이 되면 기절 |
| 체력 | 탐색·수리 시 감소. 휴식(하루 경과), 생선 통조림, 달토끼 떡으로 회복 |
| 부품 | 선체 판 3, 엔진 부품 2, 연료 셀 3, 안테나 1 → 로켓 수리 |

| 아이템 | 효과 | 얻는 곳 |
|---|---|---|
| 생선 통조림 | 체력 +40 | 크레이터, 버려진 탐사선 |
| 휴대 산소통 | 산소 +40 | 크레이터, 얼음 동굴 |
| 달토끼 떡 | 체력 +70 | 달토끼 이벤트 |

최대치(100)를 넘겨서 채워지지는 않고, 이미 가득 차 있으면 아이템을 쓰지 않는다.

- **난이도**: 쉬움 / 보통 / 어려움 — 산소 소모량, 탐색 허탕 확률, 게임오버까지의 기절 횟수가 달라짐

| 난이도 | 산소 소모 | 허탕 확률 | 게임오버 |
|---|---|---|---|
| 쉬움 | ×0.7 | ×0.6 | 5번째 기절 |
| 보통 | ×1.0 | ×1.0 | 3번째 기절 |
| 어려움 | ×1.3 | ×1.5 | 2번째 기절 |

- **목숨(♥)**: 화면 오른쪽 위에 남은 목숨이 표시되고, 기절할 때마다 하나씩 빈 하트(♡)가 된다.
  게임오버가 되면 세이브에 그대로 남고, '새 게임'(또는 게임오버 창의 '다시 도전')으로 새로 시작한다
- **이야기 이벤트**: 각 지역에 처음 도착할 때, 기지에서 쉴 때 선택지가 나옴
- **엔딩 2종**: 기본 엔딩 / 달토끼 엔딩 (얼음 동굴의 달토끼를 구하면…)
- **업적 6종 + 최단 귀환 기록**: 메뉴 > 기록과 업적. 새 게임을 해도 남음

## 구조

```
main.py               진입점
build.bat             PyInstaller로 실행 파일 만들기
game/
  config.py           밸런스 숫자, 지역, 아이템, 난이도  ← 숫자 조정은 여기
  events.py           이야기 이벤트와 엔딩 문구            ← 이야기 추가는 여기
  state.py            GameState: 저장되는 진행 데이터 + 세이브 버전 변환
  records.py          Records: 새 게임에도 남는 기록·업적·소리 설정
  save_manager.py     JSON 저장/불러오기 (원자적 쓰기, 백업, 손상 복구)
  logic.py            게임 규칙 (UI와 무관 → 단위 테스트 가능)
  ui.py               메인 화면과 애니메이션
  dialogs.py          선택지·난이도·엔딩·기록 팝업
  sprites.py          game/assets/의 그림(PNG) 불러오기
  sound.py            효과음 (직접 합성한 WAV → winsound)
  assets/             게임이 쓰는 그림: 고양이, 달토끼, 배경, 로켓, 자물쇠 (tools/make_assets.py가 생성)
art/
  moon_background.png 배경 원본 그림 (로켓·글자·자물쇠가 그려진 상태)
  cat_astronaut.png   고양이 원본 그림 (흰 배경)
  rabbit_astronaut.png 달토끼 원본 그림 (흰 배경)
tools/
  make_assets.py      원본에서 글자·자물쇠·로켓을 떼어 내 assets/를 만든다 (Pillow·numpy 필요, 개발용)
tests/                저장·로직·콘텐츠 테스트
saves/                실행 시 자동 생성 (실행 파일은 %APPDATA%\MoonCat)
```

데이터는 한 방향으로만 흐른다: **버튼 → logic이 GameState 변경 → 업적 반영 → 저장 → 소리 → 다시 그리기**

## 저장 설계

1. **저장 시점**: 모든 행동·선택 직후, 창 닫을 때, 처음 실행할 때
2. **안전한 쓰기**: `.tmp`에 먼저 쓰고 `os.replace`로 교체 → 저장 도중 꺼져도 기존 세이브가 깨지지 않음
3. **백업**: 직전 파일을 `.bak.json`으로 보관. 본 파일이 깨지면 자동으로 백업을 불러옴
4. **OneDrive 대응**: 동기화 때문에 파일이 잠시 잠기면 교체를 재시도
5. **버전 관리**: `version` 필드 + `state.migrate()` → v1 세이브도 v2로 자동 변환됨
6. **두 개의 파일**: `savegame.json`(이번 판) / `records.json`(기록·업적·설정, 새 게임에도 유지)

> ⚠️ 규칙: 재시작 후에도 남아야 하는 값은 **반드시 `GameState`(또는 `Records`) 필드에** 넣는다.
> UI 위젯이나 `Game` 객체에만 두면 저장되지 않는다.

## 콘텐츠 추가 방법

- **새 이벤트**: `events.EVENTS`에 항목 추가 (형식은 파일 맨 위 설명 참고)
- **새 지역**: `config.LOCATIONS`에 항목 추가 (`found_in`으로 어디서 발견되는지, `x`로 화면 위치 지정)
- **새 아이템**: `config.ITEMS`에 이름 추가 → 지역 `loot`에 가중치. 소모품이면 `CONSUMABLES`에도
- **새 업적**: `records.ACHIEVEMENTS`에 추가 → `Records.update_from()`에 조건 한 줄
- **캐릭터 그림 교체**: `art/`의 고양이·달토끼 원본을 바꾸고 `python tools/make_assets.py` 실행 (흰 배경 그림이면 자동으로 투명 처리)
- **배경 교체**: `art/moon_background.png`를 바꾸고 `python tools/make_assets.py` 실행.
  구도가 다른 그림이면 스크립트 맨 위 좌표(글자·자물쇠·로켓 위치)와 `config.LOCATIONS`의 `x`,
  `ui.py` 맨 위 좌표를 스크립트가 출력해 주는 값으로 맞춘다
- **세이브 형식 변경**: `config.SAVE_VERSION`을 올리고 `state.migrate()`에 변환 단계 추가
