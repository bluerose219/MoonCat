# 파이썬 미니 프로젝트

장르: 미니 게임
주어: 고양이
공간: 달나라
돌발 상황: 재시작해도 이전 상황이 남아야 한다

내 해석:달나라에 불시착한 고양이가 다시 지구로 돌아가는 미니 게임

장르와 단어, 돌발 상황은 서로 독립적으로 뽑았습니다. 조합을 이야기·화면·규칙·데이터로 자유롭게 해석하되, 각 요소를 어디에 반영했는지 설명하세요. 돌발 상황도 프로그램에서 직접 해결해야 합니다.

필수 결과: Python 프로그램, 조작 가능한 UI, 핵심 기능 3개, 돌발 상황 재현·해결 시연, 직접 수정한 기능과 시험 기록.

홈페이지의 출발 예시: 고양이 · 달나라 목표 달성 게임
기능: 시작 버튼으로 점수와 진행 상태 초기화하기 / 선택 버튼을 눌러 목표에 다가가고 점수 바꾸기 / 성공·실패 조건을 판정하고 다시 시작하기
화면: 주인공과 배경 · 점수 표시 · 행동 버튼 · 사건 알림 · 다시 시작 버튼
돌발 상황 재현: 기록을 만든 뒤 종료하고 다시 실행해 보세요.
해결 힌트: JSON 파일에 저장하고 시작할 때 읽어 오세요. 파일이 없으면 빈 상태로 시작하세요.
아이디어는 내가 바꿀 수 있습니다.

나는 코딩을 처음 배우는 사람입니다. 이 조합으로 4시간 안에 만들 수 있는 개인 Python 프로젝트를 계획해 주세요. 먼저 서로 다른 아이디어 3개를 제안하고 내가 선택할 수 있게 해 주세요. 각 아이디어에 핵심 기능 3개, 한 화면의 UI 구성, 돌발 상황을 재현하고 해결할 방법을 적어 주세요. 이야기 속 사건·게임 규칙·기능 제약 등 자유롭게 해석해 주세요. 장르 때문에 다른 단어를 빼거나 바꾸지 마세요.

아이디어를 고른 뒤에는 가장 작은 실행 가능한 버전부터 만듭니다. 이미 준비된 환경에서 사용할 수 있는 UI 도구를 우선하고 필요한 설치가 있으면 알려 주세요. 코드에는 처음 보는 용어·기호·각 기능의 이유를 한국어 주석으로 설명하세요. 파일 이름·저장 위치·실행 명령·예상 결과·오류 해결을 함께 알려 주세요. 유료 API나 별도 서버 없이도 완성 가능한 범위로 제안해 주세요. 기능 하나씩 추가하며 내가 직접 실행·시험할 수 있게 도와주세요.
